# Verified CLI examples

All 29 registered command names (25 implementations and 4 aliases) have one executed example. Detailed machine-readable records: [examples.yaml](examples.yaml). Observed evidence and versions: [verification.json](verification.json).

Run from an installed editable dev checkout, with runtime dependencies already available:

```bash
python agent_tools/validate.py
python agent_tools/examples/run_examples.py --work-dir /tmp/traceratops-examples
```

The runner creates a fresh directory per run and command, constructs small deterministic synthetic ECSV/BED/JSON/mask inputs, and copies the repository 4-barcode distance-stack fixture. The bootstrap fixture is generated by the package BuildMatrix implementation; the replot input is generated by compute_threeway_colocalization. No generated images or experimental datasets are included here. All CLI invocations execute installed entry-point scripts, not replacements. Stdout and stderr remain in the work directory.

Each invocation below is run in its freshly prepared input directory. If stdin is shown, pass that literal string to subprocess.run(input=..., text=True); it is a filename list. The FOF-CT import example first runs the export example in its own directory. Bootstrap cycle counts here are for smoke testing and are not research recommendations.
